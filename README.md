## 📘 EduResources Hub

EduResources Hub is a responsive web application built using HTML, CSS, JavaScript, and Node.js, designed to serve as a curated portal for essential learning platforms. It features categorized links for coding, JavaScript, and database tutorials, a built-in dark mode toggle for enhanced user experience, and the ability for users to suggest new resources.

This project demonstrates foundational frontend development skills including semantic HTML structuring, modular CSS styling, and interactive JavaScript functionality. Additionally, it includes a simple backend implemented using Node.js to handle user-submitted resource suggestions.

Technologies Used:
Frontend: HTML, CSS, JavaScript

Backend: Node.js (to handle form submissions and potential future expansion)

Dark Mode Toggle for a modern and comfortable user experience
